Leader key = , (IDE) · localleader = \

vide — session launcher (shell)

vide -n NAMEStart or reattach the tmux session vide_NAME
vide -q NAMETerminate session NAME
vide -lList active vide sessions (Attached/Detached)
vide -d DIRSet working directory (default: cwd)
vide -hShow help
Top pane: Vim (75%). Bottom pane: console (25%). If a file under DIR matches NAME it opens directly, else main or the first .py/.tex.

tmux — prefix is Ctrl-a

Ctrl-aPrefix key (replaces Ctrl-b)
Ctrl-a Ctrl-aSend a literal Ctrl-a through
Ctrl-a XKill current session (confirm y/n)
mouseEnabled: click panes, drag borders, scroll
v / ycopy-mode-vi: begin selection / yank & cancel
Panes collapse when unfocused; Tagbar & file explorer expand on entry.

IDE core — ,c maps (all buffers)

,cpOpen / reset IDE layout (Tagbar + Editor + Files)
,cfFind all occurrences of word under cursor
,cgJump to file+line of occurrence under cursor
,crWrite find-list edits back to source files
,cuRefresh the file explorer
,cmFetch OpenRouter free models, pick a default
,fOpen file path under cursor in editor window
Tagbar: double-click or ↵ jumps to the definition.

Find & replace workflow

  1. ,cf — grep word under cursor across .py .tex .cpp .h .hpp under cwd; results shown as an editable list.
  2. Edit list lines in place to change the text.
  3. ,cr — write modified lines back to their files.
  4. ,cg — jump to the file/line of the row under cursor.

Screen layout

vide_NAME  /  window "code"
+-------+-----------+-------+
| Tagbar|   Editor  | Files |
| symbol| main edit | netrw |
+-------+-----------+-------+
| IPython console (slime)  |
| or plain bash            |
+--------------------------+
Top = pane 0 (75%), console = pane 1 (25%). Tagbar & Files shrink to 2 cols when unfocused, expand on entry. ,cp rebuilds the layout anytime.

First run

./install.shDeploy vimrc, tmux.conf, plugins, ~/bin/vide
./install.sh -lAlso install LaTeX system deps (texlive, okular)
./install.sh -uUninstall, restore .orig backups
vide -n projLaunch / attach the IDE for session proj
Needs ~/.config/ai/openrouter.token for AI features. If claude CLI is logged in, AI routes to it by default.

Editor — clipboard & motion

y p Pnormal & visual: auto-sync with the system clipboard via xclip

No xclip installed: y/p fall back to plain vim yank/paste.

Python / Shell buffers · localleader = \

Python — IPython (vim-slime)

\ssStart IPython, Qt backend (--pylab qt)
\asStart IPython, Agg backend (non-interactive)
\hhn: send current line   x: send selection
\aaAs \hh, then advance cursor one line
\rrRun whole script (%run)
\RRRun whole script and report run time
\ddDebug current script (%run -d)
\qqExit debug mode / IPython (exit)
\QQRestart IPython
\hh/\aa are blocked with a warning unless IPython sits at an empty In [n]: prompt.

Python — code cells (# %%)

\ccExecute the current cell
\vvExecute cell verbosely, jump to next cell
\llClear console, execute cell, jump to next
\LLClear the IPython console
\xxClose all Matplotlib figure windows
[c / ]cJump to previous / next cell header
F9Insert cell header above + insert mode
F10Insert cell header below + insert mode

Python — ALE lint / fix

Ctrl-kPrevious lint error (wrapping)
Ctrl-jNext lint error (wrapping)
Ctrl-fAuto-fix file: black · isort · autoimport
Ctrl-h / ←BSShow hover documentation at cursor
Ctrl-xClose the ALE hover / preview window
Linters: pylsp (flake8, mypy/dmypy) + jedils. black line length 90. Saving a .py updates its paired .ipynb (jupytext).

Shell buffers (filetype sh)

\ssSend echo "connect" to the console pane
\hhn: send line   x: send region to console
\aaSend line / region, then advance one line

LaTeX (vimtex)

§Reformat indent of selected comment block
F9insert mode: trigger LaTeX completion
\llToggle latexmk continuous compilation
\lvForward search: view PDF in Okular
\lk / \lcStop compiler / clean aux files
\le / \ltShow errors / toggle table of contents
Compiler: latexmk (bibtex, synctex, shell-escape, nonstop). Okular inverse search → vim --servername vim. All folds open. ALE off per-buffer.

AI — vim-ai commands

:AI promptGenerate / complete text at cursor
:AIEdit instrEdit selection / context in place
